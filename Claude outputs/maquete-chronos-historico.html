Como fica no Firebase

Tudo continua no mesmo banco. As suas aulas de hoje não são movidas nem alteradas. Só entra um documento pequeno novo.

chronos/
 ├─ dados_escola      ← as aulas (CONTINUA IGUAL, nada é migrado)
 │    └─ 2h: { nome, disciplina, modulos: [
 │         { id:"b3",      titulo:"3º Bimestre - 2026", aulas:[ ...8 aulas... ] },
 │         { id:"b4-2026", titulo:"4º Bimestre - 2026", aulas:[] },
 │         { id:"b1-2027", titulo:"1º Bimestre - 2027", aulas:[] }   ← criado sozinho
 │       ] }
 ├─ turmas            ← NOVO, pequeno: quem aparece na página inicial
 │    └─ itens: [ { id:"2h", nome:"2ª Séries H e L", disciplina:"História",
 │                  grupo:"fgb", ativa:true, ordem:1 }, ... ]
 ├─ nomes_alunos      (já existe)
 ├─ config            (avisos, já existe) + NOVO campo pequeno:
 │    └─ bimestreAtual: { ano: 2026, bim: 3 }   ← o "em andamento"
 └─ mensagem_semana   (já existe)

O que grava em cada ação

Salvar aula em "4º Bimestre - 2027"
   → se o bimestre não existe, cria o módulo b4-2027 dentro da turma
   → adiciona a aula nele. Nada mais é tocado.

Renomear turma / mudar disciplina / desativar
   → altera só o documento "turmas" e o nome/disciplina da turma
     (as aulas ficam intactas)

Clicar "Passar para o 4º Bimestre"
   → muda só config.bimestreAtual. Os alunos veem o novo bimestre em
     destaque; o anterior continua no Histórico.

Virar o ano
   → o mesmo botão: do 4º Bimestre passa para o 1º do ano seguinte.
     O módulo b1-2027 é criado sozinho quando você salvar a 1ª aula.
Segurança: antes de mexer no projeto eu faço um backup novo das aulas e só publico depois de testar com uma cópia dos seus dados.
