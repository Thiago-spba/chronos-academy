# Chronos Academy — PWA de Apoio Escolar

Plataforma educacional progressiva (PWA) desenvolvida para o Novo Ensino Médio. O sistema une disciplinas de Ciências Humanas (História) e Ciências Exatas/Tecnologia (Desenvolvimento de Sistemas e Lógica), focando no protagonismo do aluno e na aprendizagem significativa.

## 🚀 Funcionalidades Principais

* **Design Dual (Claro/Escuro):** Interface baseada na Psicologia da Educação, adaptando-se entre o "Modo Clássico" (tons de pergaminho/ouro para História) e o "Modo Tech" (tons escuros e neon para Tecnologia).
* **Progressive Web App (PWA):** Instalável diretamente pelo navegador em Smartphones, Tablets e Desktops, funcionando como um aplicativo nativo.
* **Timeline Pedagógica:** Estrutura escalável com sistema de acordeão, organizando o ano letivo em 4 bimestres sem poluição visual.
* **Módulos Focados:** Cada aula possui estrutura de Introdução ("O que é isso?"), Aplicação Prática ("Para que serve?"), Material em PDF e Videoaulas.
* **Lazy Loading de Vídeos:** Otimização de performance e economia de dados. O motor de reprodução do YouTube só é carregado após a interação do aluno.

## 🛠️ Stack Tecnológica

* **React.js**
* **Vite** (Build tool e servidor de desenvolvimento)
* **Tailwind CSS v4** (Estilização e suporte nativo a Dark Mode)
* **Lucide React** (Biblioteca de ícones vetoriais em SVG)
* **Vite PWA Plugin** (Configuração de Manifest e Service Workers)
